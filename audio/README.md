# 参考音频（★ 本仓库**不附带**音频文件）

> ⚠️ **本目录只有这份说明，没有 `.wav` 文件。**
> 原因：音色版权属于**原声者**，公开再分发有风险；且每个人想用的音色不同。
> 下面教你怎么**自己准备**（GPT-SoVITS 零样本只需 5~10 秒音频，不用训练）。

---

## 一、参考音频从哪来

**音色来源：B 站 UP 主「白菜工厂1145号员工」**

- 个人空间：<https://space.bilibili.com/518098961>
- 做法：从 TA 的**公开视频**里截取一段**纯人声**（无 BGM、无混响）片段，或直接私信UP主获得网盘链接。

**⇒ 或者更推荐：录制你自己的声音** —— 零版权顾虑，见第三节。

---

## 二、音频要求（决定了克隆质量）

| 项 | 建议值 | 说明 |
|---|---|---|
| 时长 | **5 ~ 10 秒** | 太短音色不稳，太长没必要（GPT-SoVITS 零样本足够） |
| 采样率 | 32k / 44.1k / 48k | 都行；不是必须重采样 |
| 声道 | 单声道 | 立体声也能用，但单声道更稳 |
| 格式 | `.wav` | 其他格式（mp3/m4a）建议先转 wav |
| 环境 | 安静、无背景音乐、无混响 | ★ 这条最重要 —— BGM 会被当成"音色"一起学进去 |

**★ 三个最常见的坑：**

```
① 截到了带 BGM 的片段 ⇒ 合成出来会带"噪音音色"
② 截到了多人对话     ⇒ 音色会混
③ 片段里有笑声/叹气   ⇒ 语气会飘
⇒ 选【一个人、安静、平稳地说一整句】的片段最好
```

## 三、怎么截取（三个办法）

### 办法 A：录你自己的声音（★ 推荐，零风险）

```
工具：Windows 自带的「录音机」（开始菜单搜"录音机"）
内容：一句完整的话，含多个韵母
      例：「今天天气不错，我们一起出去走走吧，顺便买点东西回来。」
要求：安静房间、手机/麦克风离嘴 20cm、平常说话语气
```

### 办法 B：从视频里提取（想用 UP 主的音色时）

```bash
# 1) 下载视频（或用你已有的）
yt-dlp "<视频URL>"

# 2) 只导出音频
ffmpeg -i input.mp4 -vn -ac 1 -ar 48000 ref_raw.wav

# 3) 用 Audacity 等工具，剪出 5~10 秒【纯人声】片段，导出为 reference.wav
```

> 若视频里人声和 BGM 混在一起，需要人声分离（UVR5 / demucs 等）；
> **能换一段没有 BGM 的素材就换**，比分离出来的效果好。

### 办法 C：用工具自动切片（批量试音色）

GPT-SoVITS 自带 `tools/` 里有切片脚本，可把长音频自动切成多段，
再挑一段最干净的。

## 四、怎么用

### 4.1 放进 GPT-SoVITS

```yaml
# GPT_SoVITS/configs/tts_infer.yaml
ref_audio_path: <绝对路径>/reference.wav
prompt_text: 参考音频里说的那句话     # ★ 必须与音频内容一致，否则音色飘
prompt_lang: zh
```

**或** 用 API 请求指定（不改配置）：

```python
import requests
requests.post("http://127.0.0.1:9880/tts", json={
    "text": "你好，我是 Fairy。",
    "text_lang": "zh",
    "ref_audio_path": "<绝对路径>/reference.wav",
    "prompt_text": "参考音频对应的文本",
    "prompt_lang": "zh",
    "text_split_method": "cut5",
})
```

### 4.2 接到服务器

编辑服务器的 `data/.config.yaml`：

```yaml
TTS:
  ref_audio_path: <绝对路径>/reference.wav
  prompt_text: 参考音频对应的文本
```

## 六、没有参考音频能跑吗

**可以，但音色不是"那个角色"。**

```
GPT-SoVITS 默认自带几个预置音色（模型自带）
⇒ 不填 ref_audio_path 也能合成，只是声音是通用女声/男声
⇒ 想要特定音色，必须提供参考音频（零样本）或训练权重（微调）
```

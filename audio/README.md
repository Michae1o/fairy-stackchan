# 参考音频

本目录的 `reference.wav` 用于 GPT-SoVITS 的**零样本音色克隆**。

## 文件信息

| 项 | 值 |
|---|---|
| 时长 | 5.62 秒 |
| 采样率 | 48000 Hz |
| 声道 | 单声道 |
| 位深 | 16 bit |
| 大小 | 约 0.5 MB |

> 用法：在 GPT-SoVITS 的配置里把 `ref_audio_path` 指向这个文件；
> 或在服务器 `data/.config.yaml` 里设 `ref_audio_path: <绝对路径>/reference.wav`

## 想要更干净的做法？

**录制你自己的声音**（GPT-SoVITS 只需 5~10 秒清晰人声）：

```
要求：
  · 单声道、采样率 32k/44.1k/48k 均可
  · 时长 5~10 秒（太短音色不稳，太长没必要）
  · 安静环境、无背景音乐、无混响
  · 语气自然（就用平时说话的语气）
  · 内容建议：一句完整的话，含多个韵母（如"今天天气不错，我们一起出去走走吧"）

替换本文件即可，零版权顾虑。
```

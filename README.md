> ⚠️ **非官方同人项目** —— 与米哈游 / HoYoverse 无任何关系，未获授权或认可，

把 M5Stack **StackChan** 桌面机器人改造成《绝区零》的 **Fairy**：
换成 Fairy 的脸、用自建的语音服务（GPT-SoVITS 音色）、

## ★ 特色功能：双主题（可换成你自己的两套）

这是本项目**最核心的设计**，也是最值得你改造的地方。

设备里同时装 **两套完全独立的形象**，切换时会**自动切换所连的服务器**：

| 主题 | 长相 | 连谁 | 适合 |
|---|---|---|---|
| **Fairy**（默认） | 《绝区零》Fairy | **你自己的**服务器（人设 + 专属音色） | 在家用 |
| **Geometry**（官方） | M5Stack 官方几何脸 | **官方**服务器 `api.tenclass.net` | 带出门用 |

**为什么这样设计？**

```
自建服务器的痛点：只能在你自己家里用（离开 WiFi 就连不上）
官方服务器的痛点：没有人设、没有你的音色、没有自定义

⇒ 双主题同时解决：
   · 在家 → Fairy + 自己的服务器（人格化、音色专属）
   · 出门 → 官方几何脸 + 官方服务器（不依赖你的网络）
   切换 = 按一下【电源键】（★ 也支持语音 / 控制台，见下）
```

### ★ 换成你自己的两套主题

本项目**不限定**必须是「Fairy + 官方几何脸」。你可以换成任何两套组合，例如：

```
· 你自己的原创角色  ⇄  官方几何脸
· 角色 A（家里用）   ⇄  角色 B（办公室用）
· 带人设的自建服务   ⇄  纯语音助手（不带人格）
· 中文人设          ⇄  英文人设
```

**怎么改**：见 [firmware/README.md](firmware/README.md) 的「双皮肤是怎么实现的」章节 ——
核心就是 `skin_manager.cc` 里的 `Skin` 枚举 + 每套皮肤对应的服务器地址。
形象素材替换见下方「未包含的内容」说明。

## 这个项目做了什么

### 1. 双皮肤（Fairy ⇄ 官方几何脸）

设备里同时装两套外观，**切换时会自动切换所连的服务器**：

| 皮肤 | 外观 | 服务器 | 适合 |
|---|---|---|---|
| **Fairy** | 《绝区零》Fairy 的 GIF 脸 | 你自己的自建服务器 | 在家用，有人格 + 专属音色 |
| **Geometry** | 官方几何脸（会眨眼/有情绪） | 官方 `api.tenclass.net` | 带出门用，不依赖你自己的网络 |

两种切换方式（**都不依赖对话**，断网也能切前一种）：

1. **电源键短按** —— 直接切换（设备本地完成，最可靠）
2. **语音**：「换成官方表情」「切回 Fairy」
3. **Web 控制台** —— 皮肤页直接点卡片（需要设备在线）


### ⚠️ 关于官方几何脸皮肤（说实话）

**这一部分我们没怎么做**，现状是「移植过来能跑」，够用但不精细：

```
✔ 已经能用的：
   · 6 个情绪（Neutral / Happy / Angry / Sad / Doubt / Sleepy）
   · 说话时嘴一开一合（与官方 SpeakingModifier 同参数）
   · 摸头冒爱心、甩晕（装饰器）
   · 眼睛会眨眼

✘ 没做细的：
   · 情绪的【具体呈现】就是官方原版那套，我们没有美化/重绘
   · 没有做「一个情绪多种表情」的丰富度
   · 装饰器只用了爱心/晕眩两个，官方还有 shy / sweat / angry 没接
   · 没有做情绪的平滑过渡（是直接切换）
```

**如果你想要更丰富的表情**，可以自行构建：

```
· 素材来源：StackChan 官方固件（MIT 许可，可自由改）
     https://github.com/m5stack/StackChan
· 表情定义在：stackchan_avatar/skins/default/（eyes.cpp / mouth.cpp）
· 情绪枚举在：stackchan_avatar/avatar/elements/emotion.h
· 装饰器在：stackchan_avatar/decorators/（已有 5 个，可自行扩写）
· 我们自写的漂浮爱心可作为参考：decorators/floating_hearts.h
```

**这是我们留给你的扩展点** —— 皮肤系统结构是开放的，加情绪/加装饰器都很直接。

### 2. 状态栏

```
[WiFi]  ......  [电量]
```

> **关于设备上的菜单**：早期版本做过「状态栏 ☰ → 侧边菜单」，
> 但实测下来**触摸区域太小、体验不好**，已**整体移除**。
> 现在所有可调项都在 **Web 控制台**（见第 4 节），
> 设备上只保留「电源键切皮肤」这个最常用的操作。
>
> 如果你想要设备端菜单，可以参考早期实现思路，但更推荐用控制台。

### 3. 触摸 / 摇晃 / 说话反应

| 动作 | 反应 |
|---|---|
| 摸头顶 | 开心表情 + **冒爱心**（跳动约 1.5 秒后消失）+ 轻轻抬头 |
| 用力甩 | **晕眩**转圈 + 左右摆头 |
| 说话时 | **嘴会一开一合**（与官方 SpeakingModifier 同参数） |
| 点屏幕 | 切换对话状态（唤醒/停止） |
| 空闲时 | 随机轻轻转头（★ **默认关闭**；在控制台或语音开启） |

> 硬件说明：摸头用 **SI12T** 触摸芯片（I2C `0x68`），
> 摇晃用 **BMI270** 加速度计（I2C `0x69`）。
> **两者地址不同，可以同时使用** —— 这点容易搞错，官方固件也是这么做的。

### 4. Web 控制台

启动服务器后，浏览器打开（**端口默认 8003，可在 `data/.config.yaml` 的 `server.http_port` 里改**）：

```
http://<你的服务器IP>:8003/admin   电脑版（功能全）
http://<你的服务器IP>:8003/m       手机版 H5（小屏优化过）
```

> ⚠️ `8003` 只是**默认值**。本项目代码里所有需要 HTTP 端口的地方
> 都会**先从配置读 `server.http_port`**，读不到才用 8003 兜底
> ⇒ 你改了端口，OTA 地址推断、控制台链接都会跟着变，不用改代码。
>
> ★ **兜底时服务器会打印明确告警**（不是静默），日志里会看到：
> `[自适应提示] 配置里没有 server.http_port，OTA 地址推断将兜底使用 8003`
> ⇒ 看到这条就说明你该去 `data/.config.yaml` 补上 `server.http_port`。

#### ⚠️⚠️ 安全提示：控制台【没有登录鉴权】

```
本项目控制台是【基于内网假设】设计的简化实现：

✔ 有做： 判断请求来自内网（RFC1918 网段）还是公网
✘ 没做： 登录 / 密码 / token 校验 —— 任何能访问到该端口的人都能打开控制台

⇒ 也就是说：能访问这个地址 = 能改你的大模型 Key、人设、音色、皮肤
```

**怎么安全地用：**

```
① ★ 只在内网用（默认场景）—— 不要把这个端口映射到公网
② 需要外网访问时，用【反向代理 + HTTP 基础认证】（Nginx / Caddy 都行），
   或套一层 VPN（WireGuard / Tailscale 等）
③ ⛔ 绝对不要把 8003 直接暴露到公网 IP
④ 如果你要自己加鉴权：改 server/patches/admin_handler.py 的
   add_routes()，给 /admin 路由挂一个 token 校验中间件
   （参考 vision_handler.py 里那套 JWT 写法）
```

可改：

- 大模型 / API Key / 人设 prompt
- 音色（含试听）
- 皮肤切换（★ 直接点皮肤卡片即可切）
- RGB 灯（每个状态：常亮 / 呼吸）
- 舵机角度（可视化摇杆）
- 每页都标注了「是否需重启」

> **待机转头 / 舵机跟随** 也可以在控制台里开关，或直接对设备说
> 「开启待机转头」「关闭待机转头」。

## 快速开始

**两条路，看你有没有编译环境：**

### 路线甲：不想编译 → 直接刷现成的固件（★ 最省事）

```
① 下载固件 → https://github.com/Michae1o/fairy-stackchan/releases/latest
   （找 fairy-stackchan-universal.bin，11.9 MB）

② 刷进去（三选一，见 [firmware-bin/README.md](firmware-bin/README.md)）
   · M5Burner（官方工具，适合新手）
   · esptool（命令行，一个命令）
   · 网页版烧录器

③ 刷完连上你的服务器（★ 固件不含地址，见该文档第三节）
```

> ★ 这个固件**不含作者的任何私有配置**，功能与作者自用版完全一样。

### 路线乙：要自己编译 → 按 INSTALL 走

见 **[INSTALL.md](INSTALL.md)**。三步：

1. 准备上游项目（固件 + 服务器）
2. 覆盖本目录的改动文件
3. 改一处 IP（或让它自动识别）→ 编译 / 启动

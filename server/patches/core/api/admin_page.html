🔑 大模型（LLM）

设备与网页对话都走这里。改完需重启生效。

⚠️ 需要重启服务器才会生效。原因：服务器进程启动时读一次配置（app.py load_config()），之后一直用内存里的旧值。
⇒ 保存后请点底部 「保存并重启」（约 20~30 秒）。

🎭 人设 Prompt

Fairy 的性格设定，设备与网页对话都用它。改完必须重启。

⚠️ 需要重启服务器才会生效。人设 prompt 在启动时被载入。保存后点底部「保存并重启」。

🎤 音色（GPT-SoVITS）

⚠️ 需要重启服务器才会生效。TTS 参考音频/参数在启动时载入。保存后点底部「保存并重启」。

灯光

Fairy 身上 12 颗 RGB。每个对话状态一种颜色。 设备在线时点应用到设备立刻生效； 保存是把配置写进服务器（下次开机由设备读取）。

✅ 不需要重启服务器。点「保存」会：① 写进服务器配置 ② 设备在线时直接下发到设备（设备自己存 NVS，断电也不丢）。
若设备不在线，只写服务器；等设备上线后点一次「保存」即可补下发。

舵机

Fairy 的脖子：yaw 左右转头（-128~128，0=正前）、 pitch 抬头低头（3~87，约 45=水平）。 拖滑块 → 点转到此角度看效果 → 满意后点设为默认角度。

✅ 不需要重启服务器。「转到此角度」实时生效；「设为默认角度」会存进设备 NVS（下次开机就是这个姿势）。

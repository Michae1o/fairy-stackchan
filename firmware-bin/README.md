## 一、这个固件是什么

```
文件名：fairy-stackchan-universal.bin
大小：  ~11.9 MB（整机合并固件，含 bootloader + 分区表 + 应用）
芯片：  ESP32-S3（M5Stack StackChan / CoreS3）

★ "universal（通用）" 的含义：
   不含任何服务器 IP ⇒ 谁刷都行，不会连到别人的服务器上

   ⚠️ 但请注意：这也意味着【它第一次开机会连官方服务器】。
      怎么让它转到你自己的服务器，见第三节（★ 必读）。
```

### 和作者自己用的固件有什么区别

| | 通用版（Release 下载） | 作者自用版 |
|---|---|---|
| 服务器地址 | ❌ 不含（自己填） | ✅ 写死作者的内网 IP |
| 双皮肤 | ✅ 有 | ✅ 有 |
| 摸头/甩晕/爱心 | ✅ 有 | ✅ 有 |
| 唤醒词 | ✅ Hi Fairy + 你好小智 | ✅ 同 |
| 设置服务器地址 | ✅ **支持**（配网页填 / 语音说，见第三节） | ✅ 同 |

**⇒ 功能完全一样，只差"服务器地址"这一项。**

## 二、怎么刷

### 烧录方法 A：用 M5Stack 官方工具（推荐新手）

```
1. 打开 https://docs.m5stack.com/en/download  （或用 Chrome 内核浏览器）
   ⇒ 搜 "M5Burner"，或者在网页版烧录工具里选 StackChan

2. 用 USB-C 线把设备连电脑（★ 要数据线，不是充电线）

3. 在烧录工具里选「自定义固件」→ 选择本目录的
   fairy-stackchan-universal.bin

4. 点烧录，等待完成（约 1~2 分钟）
```

### 烧录方法 B：用 esptool（命令行）

```bash
# 装工具
pip install esptool

# 烧录（★ 端口按实际改，Windows 是 COM3 这样的名字）
esptool.py --chip esp32s3 --port /dev/ttyACM0 --baud 921600 \
  write_flash 0x0 fairy-stackchan-universal.bin
```

> ⚠️ 这是**合并固件**，所以烧到 `0x0` 就行（不用分别烧 bootloader/分区表/app）。

### 烧录方法 C：设备已有小智固件 ⇒ 用 OTA 升级

需要你自己的服务器提供 OTA 服务（本项目服务器自带），再把本固件放进 OTA 目录。
新手建议直接用方法 A（做法见 [../INSTALL.md](../INSTALL.md)）。

## 三、★★ 刷完之后：怎么让它连【你自己的服务器】

**这是最关键的一步，也是本项目最容易被误解的一步 —— 先把它说清楚。**

### ⚠️ 先讲实话：「不用编译」≠「什么都不用做」

通用固件**不含任何服务器地址** ⇒ 全新设备第一次开机会先连官方服务器
（`api.tenclass.net`）。

**想让它连你自己的服务器，有不编译的两条路**（下面的路径 B / C）——
★ 首选是**在设备自己的配网页里填一次地址**：不用联网、不用官方服务器、不用念 IP。

---

> ⚠️ **别把两个页面搞混**：早期文档写「在 Web 控制台填服务器地址」——那句是错的，
> 控制台是**你自建服务器**上的页面，设备连不上你的服务器就打不开它。
> 要填的地方是**设备自己的配网页**（配网模式下手机连设备热点打开的那个）⇒ 见路径 B。

---

#### 路径 A（要编译，本页不展开）：把地址编进固件

适合「给朋友用」：编译时把地址写死，他刷完就能连、什么都不用配。
做法见 [../INSTALL.md](../INSTALL.md) 的「方式 A」。
⚠️ 写死地址的固件**别公开分发**（会泄露你的内网 IP）。

#### 路径 B（★ 免编译推荐）：通用固件 + 在设备配网页填地址

```text
① 让设备进【配网模式】
     全新设备：第一次开机会自动进
     已配网的设备：开机后（状态还在 Starting 时）点一下屏幕；
                   或 WiFi 连不上时自动进

② 手机连设备的热点（名字见屏幕提示，形如 Xiaozhi-XXXX）
③ 浏览器打开配置页（屏幕上显示的那个地址）
④ 切到 Advanced 页签（中文界面是「高级选项」）→ 填「自定义 OTA 地址」：
      http://<你的服务器IP>:<http_port>/xiaozhi/ota/
   → 保存
⑤ 回「新 Wi-Fi」页签填你家 WiFi 密码 → 设备重启，直连你的服务器
```

> ★ 这个页签里另有「Wi-Fi 最大发射功率 / 记住 BSSID / 启用睡眠模式」三项，
> **不影响连服务器**，一般不用动（各项含义与「睡眠模式」的真实作用见
> [../INSTALL.md](../INSTALL.md) 第 1.5 节）。

> **为什么能成立**：设备配网页里本来就有这个输入框（上游 `esp-wifi-connect` 组件自带），
> 保存时直接写进设备、和固件读的是同一个设置项 —— xiaozhi 固件默认把它打开了，
> 只是官方文档从没讲过，所以大多数人没见过它。

#### 路径 C（备选）：通用固件 + 语音说地址

```text
设备先连上官方服务器（NVS 空时的默认行为），再对它说：
      「我的服务器是 http://<你的服务器IP>:8003/xiaozhi/ota/」
⇒ AI 调设备的本地 MCP 工具 self.server.set_ota_url，
  把地址【直接写进设备 NVS】
⇒ 设备重启，连上你的服务器
```

> ⚠️ **两个现实问题（所以只当备选）：**
>
> ① **必须先有官方服务器可用**（联网 + 官方服务正常）—— 纯离线环境走不通。
> ② **用嘴念 IP 很难念对**。ASR 常把 `<服务器IP>` 听成别的
>    （「一点五」/「幺五」/「一屋」都可能）。

---

### ★ 切皮肤不会丢地址

切到官方皮肤**之前**，设备会记住你填过的自建服务器地址；切回 Fairy 时自动用回来，
不用重填。（原理与实现见 [../INSTALL.md](../INSTALL.md) 第 1.5 节「自动记忆机制」。）

---

### 改过服务器端口的话

填地址时**把端口一起写全**（`http://<你的IP>:<端口>/xiaozhi/ota/`）就不会有问题；
设备侧**不再按固定 8003 猜端口**（技术细节见 [../INSTALL.md](../INSTALL.md) 第 1.5 节，
那是改代码的人才需要看的）。

### 怎么确认成功

```text
看设备屏幕 / 听它说话：
  · 成功：界面换成 Fairy 皮肤，说话是人设语气（"我在"、"收到"）
  · 串口日志（若有）：WS: Connecting to ws://<你的服务器IP>:8000/...

如果没成功：
  · 检查服务器地址对不对（浏览器能打开那个 ota/ 链接吗）
  · 检查设备和电脑在同一个 WiFi
  · 检查电脑防火墙有没有拦 8000/8003 端口
```

## 四、双皮肤怎么用

刷完之后设备里有**两套皮肤**，可以随时切：

| 皮肤 | 长相 | 连谁 | 什么时候用 |
|---|---|---|---|
| **Fairy** | 几何脸 + Fairy 人设 | 你自己填的服务器 | 在家 |
| **Geometry** | 官方几何脸 | 官方服务器 | 带出门 |

**切换方式（三种任选）：**

```
① ★ 按设备【电源键】短按 —— 最可靠，断网也能切
② 对设备说：「换成官方表情」「切回 Fairy」
③ 打开 Web 控制台 → 皮肤页 → 点卡片
```

> ⚠️ 切到官方之前，设备会**记住你的自建服务器地址**，
> 下次切回 Fairy 时自动用回来（不用重填）。

## 六、这个固件里【没有】什么

```text
✘ 没有你的服务器地址（这正是它通用、能公开的原因）
   ⇒ 代价：第一次开机会连官方服务器，需按第三节转到你自己的服务器
✘ 没有任何 API Key（Key 在服务器配置里，不在固件里）
✘ 没有 Fairy 的美术素材（见 ../CREDITS.md 的版权说明）
✘ 没有音色模型（音色在服务器侧，见 ../voice-package/README.md）
```

## 七、想自己编一个？

见 [../INSTALL.md](../INSTALL.md)（从上游拉代码 + 把本项目文件覆盖进去 + 编译）。
编译完可以按需改 `main/boards/m5stack/core-s3/config.json` 里的
`CONFIG_OTA_URL`，把服务器地址**直接编进固件**（这样连第三步都省了）。

> ⚠️ 注意：一旦写死地址，这个固件就**只适合你自己用**了，别公开分发（会泄露你的内网 IP）。

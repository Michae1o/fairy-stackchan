## 一、这个固件是什么

```
文件名：fairy-stackchan-universal.bin
大小：  ~11.9 MB（整机合并固件，含 bootloader + 分区表 + 应用）
芯片：  ESP32-S3（M5Stack StackChan / CoreS3）

★ "universal（通用）" 的含义：
   不含任何服务器 IP ⇒ 谁刷都行，不会连到别人的服务器上

   ⚠️ 但请注意：这也意味着【它第一次开机会连官方服务器】。
      怎么让它转到你自己的服务器，见第三节（★ 必读）。
```

### 和作者自己用的固件有什么区别

| | 通用版（Release 下载） | 作者自用版 |
|---|---|---|
| 服务器地址 | ❌ 不含（自己填） | ✅ 写死作者的内网 IP |
| 双皮肤 | ✅ 有 | ✅ 有 |
| 摸头/甩晕/爱心 | ✅ 有 | ✅ 有 |
| 唤醒词 | ✅ Hi Fairy + 你好小智 | ✅ 同 |
| 语音设置服务器 | ✅ **支持**（见第三节） | ✅ 同 |

**⇒ 功能完全一样，只差"服务器地址"这一项。**

## 二、怎么刷

### 烧录方法 A：用 M5Stack 官方工具（推荐新手）

```
1. 打开 https://docs.m5stack.com/en/download  （或用 Chrome 内核浏览器）
   ⇒ 搜 "M5Burner"，或者在网页版烧录工具里选 StackChan

2. 用 USB-C 线把设备连电脑（★ 要数据线，不是充电线）

3. 在烧录工具里选「自定义固件」→ 选择本目录的
   fairy-stackchan-universal.bin

4. 点烧录，等待完成（约 1~2 分钟）
```

### 烧录方法 B：用 esptool（命令行）

```bash
# 装工具
pip install esptool

# 烧录（★ 端口按实际改，Windows 是 COM3 这样的名字）
esptool.py --chip esp32s3 --port /dev/ttyACM0 --baud 921600 \
  write_flash 0x0 fairy-stackchan-universal.bin
```

> ⚠️ 这是**合并固件**，所以烧到 `0x0` 就行（不用分别烧 bootloader/分区表/app）。

### 烧录方法 C：设备已有小智固件 ⇒ 用 OTA 升级（最省事）

```
如果设备里已经有小智固件（能连上服务器）：
  1. 把你的服务器做成 OTA 服务（本项目服务器自带，见 INSTALL.md）
  2. 把本固件放到 OTA 目录，让设备自己升级
  ⇒ 细节看 xiaozhi-esp32 上游文档
```

## 三、★★ 刷完之后：怎么让它连【你自己的服务器】

**这是最关键的一步，也是本项目最容易被误解的一步 —— 先把它说清楚。**

### ⚠️ 先讲实话：「不用编译」≠「什么都不用做」

```text
设备「第一次」连哪台服务器，只有两个来源（见 ota.cc）：

    ① 设备 NVS 里存的 ota_url     —— 全新设备是【空的】
    ② 编译期写进固件的 CONFIG_OTA_URL —— 通用固件是【官方默认地址】

⇒ 所以：全新设备 + 通用固件 = 第一次开机【必然先连官方服务器】
   （api.tenclass.net，上游默认值）
```

**本项目所有能写 NVS 的入口，都要求设备「已经连上了某台服务器」：**

| # | 写入方式 | 前提 |
|---|---|---|
| 1 | 语音说「我的服务器是 …」 | 已连上某台服务器（否则收不到这句话） |
| 2 | 网页控制台切皮肤 | 已连上你的服务器（否则打不开控制台） |
| 3 | 切皮肤时自动记住 | 已连上你的服务器 |

⇒ **结论：想「刷完就直连你自己的服务器」，只有编译期写地址这一条路。**
通用固件做不到，它必须**先连一次官方服务器做中转**。

---

### 三条路，按「省事程度」排

| 路径 | 要编译？ | 首次怎么连 | 适合谁 |
|---|---|---|---|
| **A** 编译期写地址 | ✅ 要 | 开机直连，零操作 | 想一劳永逸 / 给朋友用 |
| **B** 通用固件 + 语音设置 | ❌ 不要 | 先连官方，再用嘴念地址 | 不想装工具链，且能接受念 IP |
| **C** 通用固件 + 控制台 | ❌ 不要 | ❌ **走不通** | —— |

> ⚠️ **特别说明「路径 C」**：早期文档写过「配网后在 Web 控制台填服务器地址」，
> **这个说法不成立** —— 控制台是**你自建服务器**上的页面，
> 设备连不上你的服务器，就打不开控制台，也就没法填地址。
> 这是个逻辑闭环，现已从文档移除。

---

#### 路径 A（★ 推荐）：编译期烧入地址

> **前提**：你的服务器**已经跑起来了**，并且你知道它的地址。
> 如果还没有，先做 [../INSTALL.md](../INSTALL.md) 第 2 节（服务器部分）
> —— 见该文档 1.0 节的建议工序。

```text
1. 编辑 main/boards/m5stack/core-s3/config.json，在 sdkconfig_append 里加：
       "CONFIG_OTA_URL=\"http://<你的IP>:8003/xiaozhi/ota/\""

2. idf.py build  →  idf.py -p <串口> flash

⇒ 刷完开机就直接连你的服务器，什么都不用做。
```

> ★ **给朋友用推荐这条**：你帮他编译好，地址直接编进去，
> 他拿到就能用，不用念 IP、不用碰配置。
>
> ⚠️ 代价：这个固件**只适合你们自己用**，别公开分发（会泄露内网 IP）。

#### 路径 B：通用固件 + 语音设置（不编译，但体验一般）

```text
① 设备开机、连上 WiFi（首次开机会有配网热点，按提示填 WiFi 密码）

② 此时它连的是【官方服务器】（因为通用固件不含你的地址）

③ 对着它说：
       「我的服务器是 http://<你的服务器IP>:8003/xiaozhi/ota/」
   ⇒ AI 调设备的本地 MCP 工具 self.server.set_ota_url，
     把地址【直接写进设备 NVS】（这个工具跑在设备上，不依赖服务器）
   ⇒ 设备重启，连上你的服务器

④ 之后切来切去都不会再丢（见下面「自动记忆」）
```

> ⚠️ **两个现实问题：**
>
> ① **必须先有官方服务器可用**（联网 + 官方服务正常）——
>    纯离线环境走不通。
> ② **用嘴念 IP 很难念对**。ASR 常把 `192.168.1.5` 听成别的
>    （「一点五」/「幺五」/「一屋」都可能）。
>    ⇒ 建议**一个数字一个数字念**，或写在纸上照着念。
>    ⇒ 所以**给朋友用不建议走这条**，用路径 A。

---

### ★ 自动记忆机制（它解决的是「切换不丢」，不是「首次怎么连」）

很多人会把这个机制误解成「零配置自动发现服务器」。**它不是。**

```text
它做的事：
   切到官方【之前】 → 把当前地址存进 fairy_skin/self_ota
   切回 Fairy 时    → 读回来用

⇒ 前提是：你【已经成功连上过一次】你的服务器。
```

**读取优先级**（`skin_manager.cc` `SelfOtaUrl()`）：

```text
① fairy_skin/self_ota   ← 上次切到官方前记下的（最可靠）
② wifi/ota_url          ← 设备当前在用的
③ CONFIG_OTA_URL        ← 编译期兜底
```

**⇒ 效果**：成功连过一次你自己的服务器之后，
在「Fairy ⇄ 官方几何脸」之间反复切换，**地址不会丢**。

> ⚠️ **顺序很重要**：先保证能连上（路径 A 或 B），再折腾切换。
> 否则第 ③ 层兜底若是官方地址，切回 Fairy 时会连到官方去。

---

### ⚠️ 已知限制：设备侧端口固定按 8003 推导

`skin_manager.cc` 里有个「从 WebSocket 地址推导 OTA 地址」的函数
（`RememberOtaFromWsUrl()`），推导端口时读 NVS 键 `fairy_skin/http_port`，
**读不到就用 8003**。

```text
现状（如实说明）：
  · 全项目【没有任何代码】写入 fairy_skin/http_port
  · RememberOtaFromWsUrl() 目前【没有被调用】（属保留代码）

⇒ 实际结论：如果你把 server.http_port 改成 8003 以外的值，
   请务必用【路径 A】把完整地址编进固件，不要依赖设备侧推导。
```

> 补充：**服务器侧**（`admin_handler.py`）是**会读** `server.http_port` 的，
> 读不到时还会打印明确告警：
> `[自适应提示] 配置里没有 server.http_port，OTA 地址推断将兜底使用 8003`

### 怎么确认成功

```text
看设备屏幕 / 听它说话：
  · 成功：界面换成 Fairy 皮肤，说话是人设语气（"我在"、"收到"）
  · 串口日志（若有）：WS: Connecting to ws://<你的服务器IP>:8000/...

如果没成功：
  · 检查服务器地址对不对（浏览器能打开那个 ota/ 链接吗）
  · 检查设备和电脑在同一个 WiFi
  · 检查电脑防火墙有没有拦 8000/8003 端口
```

## 四、双皮肤怎么用

刷完之后设备里有**两套皮肤**，可以随时切：

| 皮肤 | 长相 | 连谁 | 什么时候用 |
|---|---|---|---|
| **Fairy** | 几何脸 + Fairy 人设 | 你自己填的服务器 | 在家 |
| **Geometry** | 官方几何脸 | 官方服务器 | 带出门 |

**切换方式（三种任选）：**

```
① ★ 按设备【电源键】短按 —— 最可靠，断网也能切
② 对设备说：「换成官方表情」「切回 Fairy」
③ 打开 Web 控制台 → 皮肤页 → 点卡片
```

> ⚠️ 切到官方之前，设备会**记住你的自建服务器地址**，
> 下次切回 Fairy 时自动用回来（不用重填）。

## 六、这个固件里【没有】什么

```text
✘ 没有你的服务器地址（这正是它通用、能公开的原因）
   ⇒ 代价：第一次开机会连官方服务器，需按第三节转到你自己的服务器

✘ 没有 Fairy 的美术素材（见 ../CREDITS.md 的版权说明）
✘ 没有音色模型（音色在服务器侧，见 ../voice-package/README.md）
```

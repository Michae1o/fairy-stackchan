## 一、这个固件是什么

```
文件名：fairy-stackchan-universal.bin
大小：  ~11.9 MB（整机合并固件，含 bootloader + 分区表 + 应用）
芯片：  ESP32-S3（M5Stack StackChan / CoreS3）

★ "universal（通用）" 的含义：
   不含任何服务器 IP ⇒ 谁刷都行，不会连到别人的服务器上
```

### 和作者自己用的固件有什么区别

| | 通用版（Release 下载） | 作者自用版 |
|---|---|---|
| 服务器地址 | ❌ 不含（自己填） | ✅ 写死作者的内网 IP |
| 双皮肤 | ✅ 有 | ✅ 有 |
| 摸头/甩晕/爱心 | ✅ 有 | ✅ 有 |
| 唤醒词 | ✅ Hi Fairy + 你好小智 | ✅ 同 |
| 语音设置服务器 | ✅ **支持**（见第三节） | ✅ 同 |

**⇒ 功能完全一样，只差"服务器地址"这一项。**

## 二、怎么刷

### 方式 A：用 M5Stack 官方工具（推荐新手）

```
1. 打开 https://docs.m5stack.com/en/download  （或用 Chrome 内核浏览器）
   ⇒ 搜 "M5Burner"，或者在网页版烧录工具里选 StackChan

2. 用 USB-C 线把设备连电脑（★ 要数据线，不是充电线）

3. 在烧录工具里选「自定义固件」→ 选择本目录的
   fairy-stackchan-universal.bin

4. 点烧录，等待完成（约 1~2 分钟）
```

### 方式 B：用 esptool（命令行）

```bash
# 装工具
pip install esptool

# 烧录（★ 端口按实际改，Windows 是 COM3 这样的名字）
esptool.py --chip esp32s3 --port /dev/ttyACM0 --baud 921600 \
  write_flash 0x0 fairy-stackchan-universal.bin
```

> ⚠️ 这是**合并固件**，所以烧到 `0x0` 就行（不用分别烧 bootloader/分区表/app）。

### 方式 C：设备已有小智固件 ⇒ 用 OTA 升级（最省事）

```
如果设备里已经有小智固件（能连上服务器）：
  1. 把你的服务器做成 OTA 服务（本项目服务器自带，见 INSTALL.md）
  2. 把本固件放到 OTA 目录，让设备自己升级
  ⇒ 细节看 xiaozhi-esp32 上游文档
```

## 三、★★ 刷完之后：怎么让它连【你自己的服务器】

**这是最关键的一步** —— 通用固件不带服务器地址，第一次开机它会连官方服务器。

### 步骤

```
① 先把你的服务器跑起来（见 ../INSTALL.md），确认能访问：
      http://<你的电脑IP>:8003/xiaozhi/ota/

② 设备开机、连上 WiFi（首次开机会有配网热点，按提示填 WiFi 密码）

③ ★★ 让设备连上你的服务器 —— 三种方式，任选：

   【方式 A·推荐】改一行配置重新编译（一劳永逸）
       main/boards/m5stack/core-s3/config.json 的 sdkconfig_append 里加：
           "CONFIG_OTA_URL=\"http://<你的IP>:8003/xiaozhi/ota/\""
       ⇒ 刷完开机就连你自己的服务器，什么都不用做

   【方式 B】用本目录的通用固件 + 语音设置（不用编译）
       设备先连官方服务器，然后对它说（★ 见下方注意）：
           「我的服务器是 http://192.168.1.100:8003/xiaozhi/ota/」
       ⇒ AI 调 self.server.set_ota_url 写进设备，重启后生效

   【方式 C】★ 零操作（本项目已内建）
       设备只要【连上过一次】你的服务器，就会自动记住地址 ——
       原理：服务器下发的 websocket 地址里带着 IP，
             设备从中推导出 OTA 地址并存进 NVS。
       ⇒ 所以方式 B 只需要做【一次】，之后切来切去都不会丢
```

> ⚠️ **关于方式 B 的现实问题**：让用户「用嘴念一串 IP + 端口 + 路径」体验很差
> （ASR 也容易把 `192.168.1.100` 听错）。所以：
> - **给朋友用** → 建议用【方式 A】（你帮他编译好，地址直接编进去）
> - **自己换地址** → 方式 B 说一次就够了，之后靠方式 C 自动记住

### 怎么确认成功

```
看设备屏幕 / 听它说话：
  · 成功：界面换成 Fairy 皮肤，说话是人设语气（"我在"、"收到"）
  · 串口日志（若有）：WS: Connecting to ws://192.168.1.100:8000/...

如果没成功：
  · 检查服务器地址对不对（浏览器能打开那个 ota/ 链接吗）
  · 检查设备和电脑在同一个 WiFi
  · 检查电脑防火墙有没有拦 8000/8003 端口
```

## 四、双皮肤怎么用

刷完之后设备里有**两套皮肤**，可以随时切：

| 皮肤 | 长相 | 连谁 | 什么时候用 |
|---|---|---|---|
| **Fairy** | 几何脸 + Fairy 人设 | 你自己填的服务器 | 在家 |
| **Geometry** | 官方几何脸 | 官方服务器 | 带出门 |

**切换方式（三种任选）：**

```
① ★ 按设备【电源键】短按 —— 最可靠，断网也能切
② 对设备说：「换成官方表情」「切回 Fairy」
③ 打开 Web 控制台 → 皮肤页 → 点卡片
```

> ⚠️ 切到官方之前，设备会**记住你的自建服务器地址**，
> 下次切回 Fairy 时自动用回来（不用重填）。


## 六、这个固件里【没有】什么

```
✘ 没有你的服务器地址（这正是它通用、能公开的原因）
✘ 没有任何 API Key（Key 在服务器配置里，不在固件里）
✘ 没有 Fairy 的美术素材（见 ../CREDITS.md 的版权说明）
✘ 没有音色模型（音色在服务器侧，见 ../voice-package/README.md）
```

## 七、想自己编一个？

见 [../INSTALL.md](../INSTALL.md)（从上游拉代码 + 覆盖本项目文件 + 编译）。
编译完可以按需改 `main/boards/m5stack/core-s3/config.json` 里的
`CONFIG_OTA_URL`，把服务器地址**直接编进固件**（这样连第三步都省了）。

> ⚠️ 注意：一旦写死地址，这个固件就**只适合你自己用**了，别公开分发（会泄露你的内网 IP）。
